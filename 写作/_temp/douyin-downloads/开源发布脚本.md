# 《我把整套短剧 AI 生产系统开源了》抖音脚本

**类型**：技术/开源种草 · **时长**：约 100 秒 · **目标**：强钩子 + 引导留言 + 开源地址压轴
**钩子组合**：反常识 + 视觉奇观（AI 生成片段直接开画）

## Part A：完整脚本

**【0-3 秒｜钩子】**
文案：这条视频，是我用一套开源系统自动生成的。
（画面直接上 AI 生成的短剧高能片段，动作戏/情感戏切两下）

**【3-10 秒｜反常识放大】**
从剧本到成片，全自动。
我一个人，一台电脑，没动过剪映。

**【10-30 秒｜流程快切】**
你只要给一句话梗概——
它自己写剧本，
自己写规范提示词，
自己出角色锚点图、场景图、分镜图，
自己调用 ComfyUI 生成视频，
段与段自动衔接，最后自动合成一条成片。
（画面：录屏快切，每个步骤 1-2 秒，配字幕弹层）

**【30-55 秒｜三个核心卖点】**
三个我最喜欢的点。
第一，角色不换脸。锚点图把形象锁死，全片始终是同一个人。
第二，链式衔接。上一段末帧自动接下一段首帧，场景不断裂。
第三，纯本地部署。数据不出门，显卡是自己家的，跑多少都不花钱。

**【55-70 秒｜成品展示】**
给你看下成品——
（播放 1 分钟动作 demo 成片片段，或 3 段不同风格片段）
这是我刚生成的，从剧本到成片，全流程自动。

**【70-83 秒｜开源信息】**
整套系统我开源了。
MIT 协议，随便拿去用。
基于 ComfyUI 加 MiniMax H3，本地装好就能跑。

**【83-93 秒｜CTA 引导留言】**
评论区告诉我，你最想让它帮你做什么？
想要完整部署教程的，扣 1。
想知道怎么让角色一直不换脸的，扣 2。
我先出评论数最高的教程。
关注我，下期继续。

**【93-100 秒｜仓库名压轴（不露网址）】**
（画面定格：GitHub 仓库页首屏，但网址区域打码/裁剪，只保留仓库名与 README 标题）
文案：仓库地址我放在简介和置顶评论了——
GitHub 搜 comfyui-auto-drama，或者直接点简介里的链接。
拿走，去造你的第一部 AI 短剧。

## Step 6 审校记录

- **口语化**：短句为主（≤15 字），无书面腔
- **钩子强度**：反常识（「这条视频是我用系统生成的」）+ 视觉奇观（AI 成片直接开画），9/10
- **节奏**：快-慢-快，10-30 秒快切流程，30-55 秒放慢讲卖点，结尾催留言
- **合规**：无绝对化用语；「MIT 协议」「开源」为事实表述；不做能力承诺
- **AI 腔**：无「值得注意的是/首先其次最后/不是而是」句式
