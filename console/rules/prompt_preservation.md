# 提示词意图保护与润色规则

## 先建立约束快照
把输入分为：原始意图、硬约束、可增强信息、显式冲突、歧义与缺失信息。
硬约束通常包括：主体身份与数量、动作结果、品牌与文字、逐字对白、参考图继承范围、
镜头时长、画幅、交付用途和明确禁止项。润色时不得静默改变硬约束。

## 三栏约束（复杂镜头）
- must_hold / 必须保持：来自用户、批准资产和上一镜的稳定事实。
- changes_here / 本镜变化：本镜唯一允许发生的状态/位置/动作/情绪变化。
- must_not_appear / 禁止出现：根据当前高风险选择的少量失败项。

## 润色顺序
保留原始意图和叙事重心 → 把抽象词改成可见/可听/可计时/可检查的描述 →
消除主体数量/左右位置/动作时间/摄影机运动/声音规则之间的冲突 →
只补充不会改变用户选择的细节（其他放入"假设与待确认项"）→
输出修改摘要，逐项说明增强/澄清/移到适配层/保留未改。

## 冲突处理优先级
安全与权利 → 用户硬约束 → 批准项目事实 → 镜头可执行性 → 视听契约 → 美学偏好。
若两个同级硬约束不可同时成立，指出冲突并询问，不得静默选择。

## 平台分层
主提示词保持模型无关。平台适配层只放提供方特有的模型名/参考权重/种子/采样/运动强度/
首尾帧设置/API 字段；适配时不得删掉主提示词中的硬约束。

## 三种丰富程度
- 精简版：保留最少必要结构，快速试验（主目标 + 主体状态 + 数量空间 + 构图 + 核心光色 + 交付 + 1-3 风险）。
- 标准版：默认生产形式，七层全覆盖，批准资产事实用 ID/版本引用，不重复整份人物小传。
- 导演版：显式 open/close state、beat timeline、camera start/path/end、audio cues、
  continuity in/out 和三栏约束；适合对白/复杂动作/多人/多镜头/严格连续性。

丰富程度只改变表达密度，不允许改变原始意图、数量、时长、逐字内容或引用范围。

## 检查
润色后逐项对照约束快照：每个硬约束仍在；新增内容是否只是增强清晰度/可见性/一致性；
修改摘要是否逐项交代；是否把平台参数误写进主提示词。
