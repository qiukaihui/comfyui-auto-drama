# 动作、物理与视效反馈

## 动作写作公式
所有重要动作优先按：准备 → 发力 → 接触 → 反作用 → 落定，
再补触发/时间/轨迹/环境反馈/摄影机观察。动作词越多不代表动作越清楚。

## 五段物理链
- 准备：身体重心/支撑点/握持/肌肉或机械预备状态。没有准备，复杂动作从静止瞬间跳到结果。
- 发力：力量来源/方向/加速/身体协同。投掷来自腿→髋→躯干→肩→肘→手的连续发力，不是物体自己飞出。
- 接触：接触点/接触时刻/材料（拳击/脚步/轮胎/刀刃/门/地面/液体不同）。
- 反作用：施力者/受力者/道具/环境/摄影机的合理反馈（减速/形变/振动/声音/尘土/液体）。
- 落定：动作停止后的姿态/位置/道具/伤势/环境状态 = 下一镜 continuity out。

## 重量、惯性与摩擦
重物启动慢停止慢，身体需要更大重心调整；轻物加速快仍受空气和接触影响；
奔跑时衣物/背包/头发有滞后运动；急停时上身和携带物继续前冲再回落；
湿地/冰/沙/碎石/金属地面脚步反馈不同；接触阴影和压痕帮助物体读出重量。

## 投掷（必须写）
哪只手/怎样握持 → 准备姿态和重心 → 释放点/方向/速度/轨迹 → 旋转或姿态 →
撞击目标/接触点/反弹或嵌入或破碎 → 投掷者随后的手臂/躯干/重心。

## 撞击与碰撞（不只是"爆发"）
接触前速度和方向 → 接触材料（肉体/布料/骨骼/金属/玻璃/混凝土）→ 瞬间压缩/弯曲/破裂 →
受力者位移和旋转 → 施力者反冲或减速 → 声音/粉尘/碎片/火花/液体 → 谁保持控制谁失去平衡。
摄影机震动只绑定明确冲击时刻并短时间内恢复，不整镜随机抖动。

## 打斗与编排
威胁建立 → 一次攻击 → 一次防守/躲避 → 一次明确反击 → 落定。
每个节拍只有一个动作中心；写清谁先、谁因何反应；写出手脚解剖侧和屏幕方向；
避免多人同时做不同复杂动作；时长不足拆镜，不用"高速连续完成十个动作"；
打击伤势影响下一镜时写入状态版本和连续性。

## 行走、奔跑与追逐
起步：重心前移、支撑脚发力；速度：步频和步幅而非只写"快速"；路径：沿哪个锚点/是否转向/是否跨越障碍；
摄影机：与主体的相对位置和速度；环境：脚步尘土/水花/衣料/背包/呼吸；
停止：减速/滑步/碰撞/转身后的落定。追逐中屏幕方向跨切稳定，改变方向时展示转向过程。

## 爆炸时间线（结构，不伪造平台精度承诺）
预兆（光/压力/裂纹/声音变化）→ 起爆（明确源点和方向）→ 火球/冲击波（传播速度和遮挡）→
碎片（材料/尺寸/轨迹/危险区）→ 人物反应（先受光/声还是先受冲击）→
环境变化（门窗/尘土/火焰/照明）→ 余波（烟/落尘/耳鸣/物体落定）。
禁止同时要求爆炸巨大+所有人完全不动+环境无变化+声音安静。

## 粒子、烟、雨、雪与液体
粒子必须有来源/方向/尺度/速度/受力/结束：
雨打湿皮肤衣物地面并形成反光滴落；风改变头发衣摆烟雪共同方向；灰尘从撞击点扩散受光束显形并沉降；
液体飞溅来自接触点并留下新状态；火花沿金属切线或撞击方向飞出。只写"很多电影感粒子"= 无来源噪点。

## 环境视效反馈检查
地面（脚步/压痕/碎裂/摩擦痕/水花）、空气（尘/雾/烟/压力波）、光（火光/闪烁/遮挡/反射变化）、
声（接触/破裂/回声/底床变化）、道具（位移/旋转/损坏/落定）、人物（衣物/头发/呼吸/姿态/伤势）。

## 动作时长与降级
超载时：删除装饰动作 → 合并动作成清晰结果 → 减少角色数量或让背景角色保持状态 →
固定摄影机 → 拆两个镜头建立动作接点 → 复杂破坏放后期合成。不靠"快速完成"掩盖物理不可能。

## 常见失败与最小修复
| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 物体漂浮 | 接触/重量/支撑/阴影 | 写接触面、受力和落定 |
| 投掷方向错 | 释放点和屏幕方向 | 写解剖侧、轨迹、目标和碰撞 |
| 撞击无力 | 缺反作用 | 补减速、形变、位移、声音和环境反馈 |
| 动作次序错 | 没有 beat_timeline | 按时间写触发与动作阶段 |
| 身体融合 | 多人动作重叠 | 分配动作中心、空间位置和接触边界 |
| 爆炸像贴图 | 缺来源和阶段 | 写源点、冲击波、碎片、光和余波 |
| 动作没结束 | 缺落定 | 写尾帧位置、姿态、道具和环境状态 |
