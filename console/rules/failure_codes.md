# 失败码诊断速查表（生成失败定位 + 最小修复）

## 诊断决策树（先定位责任层，不默认堆否定词）
1. 症状是否违反批准资产事实（脸漂移/服装回退/道具复制）？
   → 是：修资产状态版本与参考范围（F-ID-DRIFT / F-STATE-DRIFT / F-REF-SCOPE）
2. 镜头契约是否矛盾/超载/缺首尾？→ 是：降复杂度/修契约/拆镜
3. 提示词是否遗漏/重复/含糊/混入平台参数？→ 是：最小重写
4. 平台适配是否超出能力或参数冲突？→ 是：只改适配层或换明确方案
5. 同一控制批次是否偶发？→ 是：比较随机候选
6. 是否更适合后期修复？→ 是：route_post 并记录

"结果不好"不是错误码；先描述可观察症状与证据帧/时间，再按表定位。

## 资产与身份
| 失败码 | 症状 | 责任层 | 最小修复 |
|---|---|---|---|
| F-ID-DRIFT | 脸/体型/发型/核心轮廓漂移 | 资产与引用 | 绑定批准身份锚点，去掉混合参考，不堆"same face" |
| F-STATE-DRIFT | 服装/伤势/湿度/携带物回退 | 状态版本 | 引用正确状态版本，写 must_hold |
| F-REF-SCOPE | 参考图构图/背景/光线被带入 | inherit/exclude | 只继承需要属性，排除其余 |
| F-DUP-SUBJECT | 同一角色出现两次 | 人数/描述/镜面 | 精确人数、每个 ID 一次、针对反射风险 |
| F-ASSET-MERGE | 两个角色或道具特征融合 | 参考与空间重叠 | 分离资产注入、站位和接触边界 |

## 空间与连续性

|---|---|---|---|

| F-SCREEN-DIR | 屏幕方向或解剖左右翻转 | 坐标含糊 | 同写摄影机侧/解剖侧/鼻尖方向 |

## 复测规则
- 每次只改一个主要责任层，记录 changed_variables 与 hypothesis
- 使用相同质检标准对比上一批与新批
- 连续两个批次对同一错误无改善时，停止同一路径，回到资产或镜头拆解
- 列出必须保持的资产/动作/摄影/声音字段

## 诊断输出格式
首要失败码 → 证据与时间点 → 责任层 → 根因假设 → 最小修复 →
本轮 changed_variables → 必须保持 → 复测方式 → 停止/升级条件。
