# 负向约束：少而准的风险控制

## 正向契约优先
先写主体/数量/空间/动作/摄影机/声音/连续性要怎样成立，再写必要禁止项；负向词不能替代正向契约。

弱写法：不要乱、不要多、不要错误人物、不要抖动、不要漂移。
强写法：画面中恰好两名批准角色各出现一次；摄影机从肩后中景缓慢推进到双人近景；
禁止额外人物、角色重复和无因果故障抖动。

## 风险驱动
禁止项只来自：
- 当前镜头结构的高风险（多人/镜面/复杂手部/对白/爆炸）。
- 该镜头上一批真实失败。
- 平台或模型已知且经确认的限制。
- 交付中不可接受的内容（烧录字幕/品牌文字错误）。

不要复制与本镜无关的"万能负面词库"。

## risk_focus
最多优先 1-3 个风险；每个风险 = 正向锁定 + 必要禁止项 + 评审方式 + 失败码。

## 去重
- "无配乐/不要音乐/no score"合并为一个边界。
- "不加人/无额外人物/only two characters"保留一个正向数量和一个必要禁止项。
- "无抖动"与"稳定摄影机"按意图合并；若有手持，改为禁止故障抖动。
- "无字幕/不烧录文字"区分字幕与场景内真实文字后再合并。
同义句重复不会增加权重，只会增加长度和冲突机会。

## 冲突压缩
| 冲突 | 处理 |
|---|---|
| 自然手持 + no jitter | 允许低幅人体微动，禁止无因果高频故障抖动 |
| 逐字对白 + no sound | 保留人声和指定环境声，无额外人声/音乐 |
| 雨景 + no reflections | 控制强镜面眩光，保留合理湿地反射 |
| 人群背景 + no extra people | 明确背景群众数量/模糊程度，或删除人群要求 |
| 快速动作 + no motion blur | 保留可读的自然运动模糊，不要拖影故障 |
| 黑暗剪影 + 每个面部细节可见 | 选择轮廓优先或脸部曝光优先 |

## 分类词库（禁止项按需取用，不做全量清单）
- 身份与数量：额外人物/同一角色重复/角色特征融合/未批准服装或状态回退。
- 空间与道具：屏幕方向或解剖左右翻转/关键家具道具复制/道具漂浮换手消失/场景布局重建。
- 动作与物理：动作顺序错误/无接触无重量无反作用/未脚本化动作/复杂动作被压缩成瞬移。
- 摄影机：多个主运镜/机位穿越实体/构图漂移错误焦点/无因果故障抖动随机变焦。
- 对白与声音：加词漏词错误说话者/未说话者嘴动/对白内容被视觉化/自动音乐旁白字幕无关人声。
- 光色材质：光源方向漂移/关键高光溢出或黑位完全压死/所有材质塑料化/未批准全局色偏。

## 正向与负向配对示例
| 正向契约 | 必要禁止项 |
|---|---|
| 恰好两名角色，各出现一次 | 无额外人物、无重复角色 |
| 解剖左手握唯一钥匙 | 不换手、不复制钥匙、不漂浮 |
| 低幅肩扛跟随 | 无随机高频抖动、无稳定器漂浮 |
| A 在 1-2.5 秒说逐字台词 | 无加词、B 不口型、对白不视觉化 |
| 唯一窗光来自场景左侧 | 无无来源正面补光、光源不换边 |

## 生成流程
从镜头契约列出当前风险 → 从最近失败记录补真实症状 → 为每个风险检查是否已有正向锁定 →
只保留对结果有判断意义的禁止项 → 去重中英文同义表达 → 冲突压缩 →
按身份/空间/动作/摄影/声音/光色分组排列，但总量保持克制。

## 质量门
- 正向契约优先于禁止项
- 每个禁止项来自当前风险或真实失败
- risk_focus 不超过少数高优先级问题
- 中英文和同义禁止项已去重
- 正向要求与负向限制已做冲突压缩
- 没有用万能负面词替代资产或镜头事实
