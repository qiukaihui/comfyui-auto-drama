# 表演指导：把情绪写成可见行为

## 原则
"悲伤/恐惧/愤怒/震惊"只是意图。可执行表演写：
触发 → 微停顿 → 视线变化 → 呼吸变化 → 面部变化 → 身体重心/动作 → 落定。

## 六个表演通道（每次选 2-3 个，避免全部最大强度）
- 视线：看谁、何时移开、是否锁住目标、目标在屏幕哪侧。
- 面部：眉、眼睑、嘴角、下颌、吞咽。
- 呼吸：吸气、屏住、呼出、胸口起伏。
- 停顿：反应前后留白、台词间空拍。
- 身体重心：前倾、后移、脚步、肩线。
- 手部：抓紧、松开、悬停、触碰（左右与道具接触易漂移）。

## 情绪转译词典（示例，不是固定配方）
- 克制恐惧：视线锁住威胁不快速乱看；吸气后短暂屏住；下颌收紧嘴唇微张；重心后移脚未迈出。
- 突然震惊：触发后先短停顿；眼睑张开瞳孔固定；呼吸中断或快速吸气；肩膀头部一次小幅后撤。
- 压抑愤怒：视线持续不来回扫动；下颌和咬肌收紧；呼气更慢肩线压低；握紧后克制地放松。
- 疲惫：眨眼变慢视线抬起需要时间；肩膀下沉依赖支撑；呼吸较深；动作开始前有延迟。
- 决心形成：先看向障碍或目标；呼吸从短促变为一次稳定呼气；重心从后脚移到前脚；眼神下颌稳定。

## 微停顿与反应因果
自然反应通常不是触发与动作同时发生：
听见门后撞击 → 0.2 秒停顿 → 眼睛先转向门 → 头和肩随后转动 → 右手从把手收回 → 落定。
时间很短时至少保留触发和一个可见反应，不要把五个表演节拍压在半秒内。

## 视线
写清：目标（人物/道具/空间锚点/画外方向）、目标在屏幕哪侧、是否移动、
眼睛先动还是头部先动、何时断开视线、多人对话中谁看谁谁回避。
不要写"看向左边"；写"眼睛先转向屏幕右侧门缝，头部随后只转约四分之一侧面"。

## 呼吸与声音边界
呼吸既是表演也是声音。有逐字对白时：写呼吸发生在台词前/中/后；区分可见胸口起伏与可听喘息；
没有脚本声音时不自动加入呻吟/笑声/叹气/语气词；"半笑"可只是面部表情。

## 身体重心
站立：重量在哪只脚、膝盖是否锁定、是否靠墙或桌；起步：重心先移支撑脚再离地；
后退：身体先缩回还是脚先探路决定恐惧程度；下蹲：髋/膝/脚/上身协调；撞击：重心被打断产生反作用。

## 主体与背景表演层级
主表演者完成镜头叙事变化；次表演者做一个可见反应或保持状态；
背景角色执行低幅度持续动作或明确静止。禁止所有角色第一帧同时高强度移动/转头/说话/挥手。

## "静止"写法
身体位置、头部方向、双手和脚步保持不变；允许自然眨眼和很弱胸口呼吸；
不说话、不转头、不做手势。若必须雕像级零微动，明确禁止眨眼和呼吸（会降低真人感）。
"保持静止"和"持续表现强烈恐惧"可以共存：恐惧通过已建立的表情和低幅呼吸保持，不新增动作。

## 对话表演
台词前：视线/吸气/决定开口的微停顿；台词中：自然语速/重音/声音强度/是否保持视线；
台词后：嘴唇停止/呼气/视线或身体落点；未说话者：明确一个反应，不让其同步口型；
台词提及的过去事件默认只存在于声音，不自动视觉化。

## 常见失败与最小修复
| 症状 | 原因 | 最小修复 |
|---|---|---|
| 表演僵硬 | 只有情绪词 | 加触发/视线/呼吸/一个重心变化 |
| 表演过度 | 所有信号最大化 | 保留两到三个通道，降低动作幅度 |
| 所有人抢戏 | 未分主次 | 指定主表演者，其他人只做一个反应或静止 |
| 未说话者嘴动 | 声音边界缺失 | 明确只有说话者口型，其他嘴唇静止 |
| 反应顺序错误 | 没有触发链 | 写触发→停顿→眼睛→头/身体 |
| 静止角色乱动 | "静止"范围含糊 | 列允许微动和禁止动作 |
