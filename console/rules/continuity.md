# 连续性控制（跨镜头状态账本 + 三栏约束）

## 原则
连续性不是"保持一致"，而是把上一镜输出变成下一镜输入；
未记录变化的字段默认保持，禁止用新形容词悄悄改动连续性。

## 八类连续性
1. 身份：脸/体型/年龄段/发型核心轮廓/道具几何保持；镜头只引用批准资产 ID 和状态版本。
2. 状态：服装层级/伤势位置/湿度/污渍/携带物/门的开合/道具损坏，保持或有明确变化事件。
3. 空间：场景分区/出入口/唯一家具/人物相对位置/前中后景可追溯；换机位不等于重建房间。
4. 轴线与屏幕方向：对话轴线/运动方向/视线方向/解剖左右保持；越轴或转向必须可见、可解释。
5. 动作：上一镜手/脚/道具/身体方向/动作阶段成为下一镜 open_state；动作接切匹配
   接触前/后、抬手/落手、起步/落脚等阶段。
6. 光线与曝光：固定光源场景位置/色温/天气/互动光/曝光重点保持；换机位可改变明暗面，
   但不能让窗光瞬移。
7. 天气与环境：风向/雨雪强度/积水/烟尘/火焰/破坏/能见度保持或记录变化。
8. 声音：环境底床/持续机器声/警报/音乐/角色声音距离/声音桥有 continuity key；
   画面切换不自动重置同一空间声音。

## 三栏约束（每个复杂镜头必写）
- must_hold / 必须保持：身份、精确人数、批准状态、轴线、唯一物体、逐字台词等稳定事实。
- changes_here / 本镜变化：本镜唯一允许改变的表情/动作/伤势/位置/环境状态；每项写明触发事件。
- must_not_appear / 禁止出现：由本镜高风险推导的额外人物、重复道具、错误口型、自动字幕等。

## 镜头首尾卡
- open_state：位置/朝向/姿态/视线/表情/手脚道具接触/服装伤势天气/摄影机起始关系/持续声音。
- close_state：同样字段的尾帧；下一镜若不直接连续，标记时间跳跃/地点跳跃/省略动作。

## 变化账本
之前状态 → 触发事件 → 本镜可见变化 → 之后状态 → 从哪个镜头开始生效 → 是否需要新资产状态版本。

## 跨场次与特殊类型
- 同场次直接连续：严格继承上一镜 close_state，只允许 changes_here 中的变化。
- 同场次省略时间：记录省略时长与允许变化；重大伤势/换装/道具转移不得无说明发生。
- 跨场次：允许时间/地点/服装/环境改变，但新 scene open_state 必须有来源；
  角色身份与故事状态仍保持。
- 梦境/幻觉/闪回：作为明确场次或镜头类型登记，不由对白内容自动触发；
  视觉规则与返回现实的接点单独写。

## 审核顺序
身份与精确人数 → 状态版本与道具 → 空间/轴线/屏幕方向 → 动作接点 →
光线/天气/环境 → 声音与剪辑桥。
先修高影响事实，不用调色或风格掩盖身份、人数或动作错误。

## 豁免
若选中镜头存在可接受的连续性缺陷，记录：问题/影响/原因/批准人/适用范围/后期修复；
口头"没关系"不能让 locked 镜头跳过质量门。
