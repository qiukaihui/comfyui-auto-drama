# 视频镜头契约（12 段导演版，H3 扩写必须逐项覆盖）

适用：扩写/润色任何视频提示词时，按 12 段契约组织画面描述；段落内顺序固定，不必写小标题。
一段镜头只承担一个主叙事功能；无法同时容纳的动作/对白/运镜 → 拆镜，
禁止用"快速完成所有动作"掩盖物理不可能。

## 12 段契约（必填项与写法）

1. 镜头目标与叙事功能
   本镜让观众[理解/感受/发现]……；通过[一个主要可见事件]完成；结束落在[信息/情绪]。
   一个镜头只有一个主功能；"高级/震撼/电影感"必须转译为可观察结果。

2. 精确角色数量、稳定 ID 与允许集合
   画面中恰好 [N] 个主体：[角色名] 各出现一次；未列出的角色不在画面和空间中。
   画外说话者要写明是否计入空间；镜面/屏幕/海报/玻璃反射不得产生额外人物。

3. 当前外观、状态与引用范围
   身份不变量（脸型/体型/轮廓/标志特征）与当前状态（服装/伤势/湿度/污渍/携带物）分开；
   服装发型与【资产状态】一字不差；参考图写清 inherit（只继承什么）与 exclude
   （排除原图姿势/构图/机位/光线/背景/调色）。

4. 场景、空间、屏幕方向与唯一道具
   场景区域 + 前中后景 + 站位（屏幕左/右 + 深度层）+ 朝向/视线 +
   唯一道具（数量/所有者/位置/谁的哪只手接触）；验收：能画出粗略平面图。

5. open_state / beat_timeline / close_state
   open_state：首帧姿态/视线/道具/环境/声音状态；承接上段时写
   "承接上段末帧：人物位置/手部/视线/服装"（continuity in）。
   beat_timeline：按秒给 触发→动作→对白→碰撞→反应→停顿 的时间段，禁止越界/重叠。
   close_state：尾帧位置/姿态/道具/表情/环境/声音（供下一段直接引用）。

6. camera_start / camera_path / camera_end
   起点构图（机位方向/高度/景别/对焦对象）→ 一个主运动（类型+方向+速度+距离+稳定方式）
   → 终点构图（结束景别/主体关系/对焦/下一镜接点）。
   禁止"推进+环绕+快速甩镜"多主运动并存；路径必须物理可走通，不穿墙/穿人/穿唯一家具。

7. 光线、曝光、色彩、材质与天气
   真实光源（来源+方向+软硬）、曝光保护优先级、主/辅/强调色、关键材质
   （皮肤/布料/金属/玻璃/湿面）不同响应、天气同时作用于人物和环境。
   禁止无来源"电影灯光"；禁止自然光与棚拍三点光冲突。

8. 表演、视线、呼吸与动作物理
   情绪转译为可见表演（触发→微停顿→视线→呼吸→面部→重心→落定）；
   动作按 准备→发力→接触→反作用→落定；抽象情绪至少两个可见/可听信号。

9. continuity_in / continuity_out 与三栏约束
   must_hold：身份/精确人数/批准状态/轴线/唯一物体/逐字台词等稳定事实。
   changes_here：本镜唯一允许变化（表情/动作/伤势/位置/环境状态），每项有触发事件。
   must_not_appear：按本镜风险推导的禁止项，只列 3-5 条，不与正向要求冲突。

10. 逐字对白、audio_cues 与混音边界
    说话者用 H3 官方稳定 ID（S1)(S2)…，全片固定；<d>[Chinese] 内只放纯对白；
    台词按自然朗读实测给时间窗 → 尾拍静默；未说话者嘴唇静止；
    对白不视觉化（不触发闪回/幻象/额外人物）；无配乐时明确 N/A。

11. risk_focus 与针对性负向约束
    最多优先 3 个风险；每个风险 = 正向锁定 + 必要禁止项 + 失败码；
    禁止用大量通用否定词堆砌（详见 negative_rules 规则）。

12. 交付规格与平台适配层
    时长/画幅/用途与平台参数（参考槽/权重/seed/采样/运动强度）分离；
    平台适配不得删改主提示词硬约束；未知平台写 unspecified。

## 动作与时长预算（发现超载时使用）
| 内容 | 通常至少预留 |
|---|---|
| 观众读清初始状态 | 0.3-0.8 秒 |
| 简单反应 | 0.5-1.2 秒 |
| 一次完整身体动作 | 1-3 秒 |
| 短句对白 | 按自然朗读实测并留前后停顿 |
| 冲击后的可见落定 | 0.3-1 秒 |

超载处理顺序：删装饰动作 → 合并动作 → 减台词 → 降摄影机运动 → 拆镜。

## 验收清单
- 删除风格词后仍能说清本镜为何存在
- 首帧与尾帧可分别画出草图；路径只有一个主意图
- 动作+对白总时长 ≤ 镜头时长
- must_hold 与 changes_here 不冲突；每个禁止项可追溯到本镜风险
- continuity_in 来自上一镜事实，continuity_out 可被下一镜直接引用
