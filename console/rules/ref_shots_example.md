## 对照要点（学这个示范的什么）
- 开头 1-2 句定镜头语言/光线/表演基调，然后 Scene context 交代当前状态
- 参考图清单逐张写 UUID + [imageN] + 外观要点 + 用途（Appearance reference only）
- STRICT 行精确人数 + 每人 ONLY 唯一特征，防止身份漂移
- 每个 SHOT 写景别 + 焦段 → 动作因果（pull→swing→hit→kicks in）→ 对白逐字
- 一个镜头一个主运动（Close-up / Wide / Quick close-ups / low-angle）
- 结尾 SFX 列表绑定可见接触 + 总时长
- 未列出的年代/风格不脑补；示例里的 Cloudy day 来自场景上下文，不是模板
