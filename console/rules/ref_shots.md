# 参考图清单 + 分镜时间轴 提示词写法（Jaxx 风格 · 精简规则版）

适用范围：生成带参考图的 H3 视频提示词、分镜图提示词、角色/场景锚点提示词时，
按本规则组织内容。禁止用「场景名 + 一句风格词」的最简写法交差。
完整示范见规则 ref_shots_example（按 rule_router 路由按需注入，或人工查阅）。

## 完整结构（按顺序）

1. 风格与场景上下文（开头 1-3 句）
   - 镜头语言 / 焦段 / 光线 / 色调 / 运镜风格 / 表演基调
     （如 35mm Kodak 500T、handheld dynamic cinematography、soft diffused daylight…）
   - Scene context：本段发生在哪、当前状态（谁在什么位置、正在做什么）
   - 只写剧本里有的信息；剧本没写的年代 / 风格不得脑补

2. 参考图清单（有参考图时，逐张按 <Picture N> 连接顺序列出；没有参考图就省略）
   <Picture N> — 用途（身份锁定 / 场景基准 / 道具外观 / 底图）+ 继承范围
   （inherit/exclude，按 ref_link 规则）+ 该图内容一句话
   - 角色图：必须附一句外观要点（发型/服装/标志物/肤色），保证脱离参考图也能识别
   - 场景图：附一句空间要点（布局/陈设/氛围）
   - 道具图：标注「外观参考 only」
   - 参考图标签用 <Picture N>（1 基，按连接顺序）；参数名以 ComfyUI 节点为准，
     不把 <Picture N> 当参数名写进请求

3. 角色卡与 STRICT 锁定
   每个出场角色一行：角色名 = ONLY 唯一身份特征（发型/服装/标志物/肤色）。
   明确禁止与任何其他角色混淆；同一角色多视图标注「同一人」；
   身材/体态以本次提示词文字为准（参考图不锁定身材）。

4. 分镜时间轴（每个镜头一段）
   SHOT N: 景别 + 焦段（Close-up 50mm / Wide 24mm …）→ 谁做了什么
   （动作因果逐步：触发→准备→发力→接触→反作用→落定）→ 对白逐字
   （H3 用 (Sx) 音色 ID + 发声时间窗）→ 运镜（起点构图 + 一个主运动 + 终点构图）
   → 承接上段末帧（continuity in，写人物位置/手部/视线/服装）/ 结尾 close_state
   （尾帧位置/姿态/道具/表情/环境，供下一段直接引用）。
   一个 SHOT 里只保留一个主运动，动作与对白必须在镜头时长内可完成。
   SHOT 卡与 film_contract 规则（12 段镜头契约）逐项对应；时长按预算执行：
   初始状态 0.3-0.8s / 简单反应 0.5-1.2s / 一次完整身体动作 1-3s / 短句对白实测留停顿。

5. 声音与时长（结尾）
   SFX 列表（绑定可见接触；禁用强爆破词）、非语言人声、总时长（如 15s）。

6. 负面约束（STRICT 行 + 风险负向）
   STRICT: EXACTLY N people. No duplicates.
   每个角色唯一特征；无多余人物/肢体/多手多脚/身份漂移/服装回退/文字水印；
   剧本没写年代/风格时不写「无现代物品」等未提及约束；负向少而准，
   只防本镜真实风险（人数/左右/口型/重复角色），先正向契约再禁止项（见 negative_rules）。

## SHOT 卡标准字段（每个 SHOT 至少覆盖）
- open_state：首帧人物姿态/视线/道具/环境（承接上一镜 close_state）
- 动作因果链：触发 → 准备 → 发力 → 接触 → 反作用 → 落定
- 对白：说话人 (Sx) + 逐字台词 + 发声时间窗 + 尾拍静默；未说话者嘴唇静止
- camera_start → 一个主运动（类型/方向/速度/稳定方式）→ camera_end
- 尾帧 close_state：位置/姿态/道具/表情/环境（下一镜可引用）
- 时长：动作+对白总时长 ≤ 镜头时长

## 要点
- 参考图清单必须逐张写清用途与继承范围，禁止只写「参照参考图」
- 每个角色的外观要点每场都要写，禁止「同上」「参照角色设定」这种偷懒写法
- 动作按因果链展开，禁止「两人互动」「深情对视」这类不可拍的空话
- 对白逐字保留并给时间窗，禁止整段塞进 <d>
- 完整示范（35mm 底片风格 + 参考图清单 + STRICT + SHOT 1-4 时间轴 + SFX）见
  规则 ref_shots_example
