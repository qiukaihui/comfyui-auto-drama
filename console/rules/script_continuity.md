# 剧本级连续性契约（段间衔接 + 动作因果链，防穿帮）

适用：剧本生成 / 剧本改写 / 剧本片段转换时，每个分镜必须满足本规则。
目的：把"上一段结束在哪 → 这一段从哪里继续 → 结束时落在哪"写清楚，
避免扩写、生图、成片出现瞬移、道具凭空出现、状态回退、人数突变等穿帮。

## 段间四连检查（每个分镜过一遍）

1. 位置连贯
   - 上一段结尾人物在哪、面向哪、姿势如何；本段开头必须从那里继续
   - 同场景内禁止瞬移（说完话还在门口，下一段直接出现在床边 = 穿帮）；
     移动必须可拍（走路/跑/转身/进门），或明确写省略（"镜头一转，已走到……"）
   - 换场景/时间跳转必须写明（如"他冲出教室，下一幕操场"），不得无声切换

2. 道具连贯
   - 道具的拿、放、传、掉落、损坏都要有明确动作事件，且发生在可见动作里
   - 禁止道具凭空出现/凭空消失：上一段手里拿的伞，下一段必须交代放哪了
   - 关键道具跨段保持（手机/信/礼物盒/武器），谁拿着、在哪只手要一致

3. 状态连贯
   - 服装、伤势、湿身、污渍、发型、携带物跨段保持，或写明变化事件（"被打了一拳，嘴角流血"）
   - 环境状态跨段保持：门开合、灯亮灭、天气、破坏、烟尘不得无说明改变
   - 情绪状态可连续发展，但禁止无触发地情绪跳变（"刚才还在笑，下一段突然崩溃"要有诱因）

4. 人数与出场管理
   - 角色进入/离开画面必须交代（进门/入画/离场/出画），禁止无交代多一个人或少一个人
   - 画外音角色要注明是否在场；多人场景人数固定，不在场角色不得出现在动作描述里

## 动作因果链（段内）
- 每段动作按 触发 → 准备 → 发力 → 接触 → 反作用 → 落定 组织；
  只写"他生气地摔门"不算完成，要写触发（听到什么/看到什么）与落定（门关上后的状态）
- 禁止"突然/瞬间/下一秒/凭空"式跳跃动作；重要动作必须有起因和可见结果
- 一段只保留一个主动作；动作密度超过段时长就拆段，禁止"快速完成十个动作"
- 动作+对白总时长 ≤ 段时长（默认 5-15 秒）；长对白段要减少动作密度

## 时间与转场
- 段内时间连续；跨段时间跳转必须写明（"数小时后""第二天清晨"）
- 白天/黑夜/天气变化要有交代，不得无声跳变
- 场景切换写清转场方向（出→入、远→近、内→外），为镜头设计留出接点

## 剧本字段写法（防止信息缺失）
- scene：地点 + 时间（日/夜/清晨/黄昏），如"教室，午后"
- action：谁 + 从哪来/在哪 + 做什么 + 怎么做 + 结束时在哪（可拍、可演、可画）
- camera：一个主运镜（起→落），不堆叠多个运镜
- dialogue：与动作因果绑定（台词承接上一个动作或引发下一个动作）

## 逐段自查清单
- [ ] 本段开头能接上上一段结尾（位置/道具/状态/人数）
- [ ] 本段结束时留下可被下一段接续的状态（尾帧落定）
- [ ] 道具/服装/伤势/环境变化都有明确事件，无凭空出现消失
- [ ] 动作有触发与落定，无"突然/瞬间"跳跃
- [ ] 换场景/时间跳转有交代
- [ ] 动作+对白时长 ≤ 段时长

## 常见穿帮点（写剧本时主动规避）
- 同场景瞬移（对话位置和下一段位置对不上）
- 道具凭空出现/消失（手里东西下一段没了）
- 人数突变（没交代进出，画面多/少人）
- 状态回退（受伤/湿身/换装下一段恢复原样）
- 动作无因果（"生气→突然跪下"没有触发）
- 时间跳变无交代（白天直接变黑夜）
