# 摄影机与剪辑语言

## 摄影机契约最小闭环
起始构图 → 一个主运动 → 稳定方式与对焦 → 结束构图 → 下一镜接点。
只写"镜头推进"没有距离/速度/对焦/结束构图，无法评审是否正确。

## 起始构图
机位方向（正面/侧面/肩后/主观/俯视/仰视）+ 机位高度（地面/腰部/胸口/眼睛/头顶）+
景别（大远景/全景/中景/中近景/近景/特写/极特写）+ 主体位置与占比 +
前中后景关系 + 对焦对象与景深 + 屏幕方向与轴线。

示例：人物解剖左后方肩后中景，摄影机略低于肩线；人物占屏幕右三分之一，
门缝在左中景；焦点在她悬停的右手。

## 焦段视觉效果（毫米数是辅助，先写视觉效果）
| 视觉效果 | 常见用法 | 风险 |
|---|---|---|
| 强广角空间展开 | 强调环境尺度/前后距离/速度 | 近脸变形、边缘拉伸 |
| 自然透视 | 对话、日常动作、克制观察 | 空间戏剧性较弱 |
| 中长焦压缩 | 隔离人物、压缩背景、亲密表演 | 动作空间和环境关系变弱 |
| 微距 | 材质、眼睛、机械细节 | 景深极浅、动作难保持 |

禁止同时要求极广角夸张和强长焦压缩。

## 一个主运动（必填参数）
| 主运动 | 观察效果 | 必填参数 |
|---|---|---|
| locked | 等待表演进入构图 | 是否允许呼吸式微动 |
| pan | 横向重新分配注意力 | 起止对象、方向、速度 |
| tilt | 垂直揭示尺度或信息 | 起止高度、速度 |
| push/dolly in | 缩短距离、增加压迫或亲密 | 距离、速度、终点景别 |
| pull/dolly out | 揭示环境或隔离 | 距离、速度、终点关系 |
| track/follow | 与主体共同移动 | 相对位置、距离、速度 |
| orbit | 改变主体与背景关系 | 角度、方向、半径、终点 |
| crane/boom | 改变高度和空间层级 | 高度、路径、终点 |
| handheld | 人体参与感 | 幅度、频率、步伐、是否跟随呼吸 |

"先推近再环绕"通常是两个主运动：删除其一、拆成多镜头，或明确第二段只是小幅构图修正。

## 稳定方式
- 锁定：构图不漂移，仅允许极弱人体呼吸微动（明确写）。
- 稳定跟随：运动平滑但有重量，不等于无摩擦漂浮；写加速、减速和停止。
- 自然手持：小幅水平/垂直变化、步伐和呼吸节奏；写幅度和主运动关系，不用"每帧随机抖动"。
- 重度肩扛：构图边缘是否可短暂切到、是否允许焦点追赶要说明。
- 故障抖动（无因果高频跳动/画面撕裂/随机位移）是失败不是手持；冲击震动绑定明确碰撞时刻并恢复。

## 对焦与景深
单一对焦对象优先；拉焦写起点/触发/终点/时长；复杂动作不要求极浅景深+所有层始终清晰；
对白镜头关注说话者但不意味着未说话者完全失焦（可用层次保持反应可读）；
镜头结束对焦对象服务下一镜接点。

## 屏幕方向与轴线
对话两人通常 A 看右、B 看左；运动方向跨切保持，除非镜头展示转向；
过肩镜头明确肩膀属于谁、前景肩在屏幕哪侧；侧脸明确摄影机位于哪一解剖侧、鼻尖指向哪一屏幕侧；
有意越轴要设计视觉桥梁（中性镜头/移动镜头），不让生成结果偶然越轴。

## 多镜头切点
需要：精确镜头数量、每段时长、每段起止构图、切点类型（HARD CUT/动作匹配/视线匹配/声音桥）、
动作接点（手/脚/道具/方向）、最终镜头落点。总时长 = 各段可读时间 + 切点/转场预算 + 落点停留。
示例结构：CUT A 0.0-2.0s 中景建立 A 抬头，尾帧视线指向屏幕右上。HARD CUT。
CUT B 2.0-5.0s A 的视线匹配到屋顶上方目标，摄影机锁定，目标从左向右进入。

## 常见失败与最小修复
| 症状 | 先检查 | 最小修复 |
|---|---|---|
| 运镜乱跳 | 多个主运动 | 只保留一个，其他改微调或拆镜 |
| 终点错误 | 缺 camera_end | 写结束景别/位置/对焦/接点 |
| 手持像故障 | 稳定方式只有"handheld" | 写幅度/节奏/身体来源/恢复 |
| 主体出画 | 路径与主体速度不匹配 | 写相对距离和跟随位置 |
| 焦点漂移 | 多个对焦对象 | 选主对象，必要时一次触发拉焦 |
| 左右翻转 | 机位侧和屏幕方向含糊 | 同时写解剖侧/摄影机侧/鼻尖方向 |
| 多镜变一镜 | 缺切点和段落时长 | 写镜头数量、明确切点与每段契约 |
