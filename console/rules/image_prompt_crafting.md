# 图片提示词创作（11 类信息结构）

适用：角色锚点图/场景参考图/分镜图/封面等所有文生图提示词。
图片提示词不是形容词清单：先锁主体和空间，再设计摄影光色材质，最后加少量风险约束。
简单图片可以压缩表达，但关键事实不能消失。

1. 主体与精确数量
   画面中恰好 [N] 个[主体类型]：[ID/名称]；主次关系为……；除列出主体外无人/无同类物体出现。
   审核：能否在一秒内数清所有允许主体？数量词之间是否一致？

2. 身份锚点
   [稳定 ID]；身份不变量 = 脸型/体型/比例/核心轮廓/标志特征；参考图只继承身份属性。
   审核：删除服装和场景描述后，剩余信息仍足以辨认同一主体吗？

3. 当前外观与状态
   [资产 ID@版本]；当前状态 = 服装层级 + 表面状态 + 伤势 + 配饰 + 携带物；
   未列出的身份不变量保持。审核：每个状态变化能否追溯到场次或上一镜？

4. 动作、姿态与接触
   [重心/支撑脚]；[解剖侧手臂/手指]接触[物体位置]；视线指向……；捕捉动作的[准备/接触/落定]瞬间。
   审核：重量落在哪里？每只关键手脚在做什么？主体与道具是否有真实接触阴影？

5. 场景、空间与唯一锚点
   [场景 ID+区域]；前景/中景/背景分别为……；固定出入口在……；恰好一个[关键锚点]位于……。
   审核：能否画出粗略平面图？关键锚点的数量/深度层/相对位置是否唯一？

6. 构图、机位与画面关系
   [景别]；摄影机位于[方向+高度+俯仰]；主体占画面[比例]并落在[区域]；为[用途]保留[方向]留白。
   审核：能否用矩形草图标出机位、主体占比和留白？

7. 镜头语言、透视与对焦
   [广角/自然/压缩]透视，[焦段感]；焦点在[对象+部位]；景深让[哪些层]清晰/柔化。
   审核：透视选择是否服务叙事？对焦对象是否唯一？毫米数与视觉效果一致吗？

8. 光源、曝光与体积
   主光来自[真实来源+方向]，质地[软/硬]；辅光/反射为……；保护[高光/肤色/暗部]；阴影落向……。
   审核：每束主要光能否找到场景来源？曝光优先保护什么？

9. 色彩、材质与表面响应
   主色[作用]、辅色[作用]、强调色[小面积焦点]；[材质]具有[粗糙度/反射/透光/磨损/湿度]。
   审核：不同材料在同一光下是否仍能区分？强调色是否真的少量且指向视觉焦点？

10. 风格、媒介与视觉来源边界
    [媒介]；画面特征 = 线条/颗粒/色块/动态范围/镜头质地；参考只继承[明确属性]，
    不复制[构图/角色/IP]。审核：去掉专有名字后风格仍可执行吗？用户是否有权使用参考？

11. 技术用途与针对性风险约束
    [画幅+方向+用途+裁切安全区]；禁止[最多若干具体风险]；平台私有参数（seed/steps/模型名）另列。
    审核：规格是真实交付字段还是形容词？每个禁止项是否对应当前画面的已知风险？

## 重要边界
- 身份与状态分开：把状态变化合并进新身份描述 = 跨图"同名不同人"。
- 参考图必须有 inherit/exclude；不写"完全照着参考图但换个场景和镜头"（自相矛盾）。
- "8K 质感"是形容词，不是实际 8K 文件；交付规格与视觉目标分开。
- 有文字/手部/重复物体风险的画面才写对应禁止项；不堆通用负面词。

## 检查顺序
主体与数量 → 身份/状态 → 空间与接触 → 构图机位 → 光色材质 → 风格边界 → 技术用途与风险。
