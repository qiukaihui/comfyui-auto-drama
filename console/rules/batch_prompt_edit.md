# 批量提示词统一修改规则（一键改所有段落 / 替换同一内容）

适用：用户给一条修改指令，同时应用到全部 H3 提示词段落（如"把'浅蓝色连衣裙'全部改成'红色连衣裙'"
、"给所有段落加雨夜氛围"）。任务：对【每一条】提示词做【完全相同】的修改，
保持各段原有结构，未涉及指令的内容一字不动。

要求：
1. 先识别指令类型：
   - 替换类（"把 X 改成 Y"）：对所有段落中出现的 X 全部替换为 Y；某段没有 X 就原样返回该段
   - 增删类（"给所有段落加雨夜氛围 / 删掉参考图清单"）：对每段在对应位置补充/删除，不改变其他内容
   - 全局风格类（"全部改成古风"）：统一调整风格头与光色描述，但不得改变剧本已有的事件、
     对白、人物关系与人数；剧本没写年代/风格时不得脑补
2. 逐段处理：每段提示词都必须出现在输出里（条数与输入一致、顺序一致），
   禁止合并、丢弃、重排或新增段落
3. 原文保真：未涉及修改指令的内容逐字保留；三大字段结构
   （integrated_multimodal_description / overall_soundscape / non_diegetic_music）保持不变；
   对白除非指令明确要求，否则逐字保留（含 <d>[Chinese] 包裹）
4. 参考图标签 <Picture N>、STRICT 身份锁定行、负面约束除非指令明确要求，否则保持原样
5. 替换要精确：只替换指令点名的内容，不得顺带改写同音/近似内容或"顺手优化"
6. 输入中某段为空字符串时，输出对应空字符串占位
7. 只输出 JSON 数组：[{"id": 1, "prompt": "..."}, ...]，条数与输入一致；
   不要输出任何其他文字、解释或 markdown 代码块标记
